      CVE-2026-109618Critical CVSS 4.0: 9.2

      Remote code execution via
      out-of-memory handling

      PHP uses longjmp() to exit the current context when an out-of-memory error occurs. Some contexts may not account for that exit and can leave request memory uninitialized. Cleanup for the request may then read or branch on that memory. Multiple out-of-memory strategies can consistently trigger the condition and lead to remote code execution.

      Weakness CWE-824 — Access of uninitialized pointer
      CVE-2026-109619Critical CVSS 4.0: 9.2

      Remote code execution via
      stale global state

      Request-owned error, session, object, or extension state can remain in persistent worker globals after its memory is freed. A later request handled by the same worker may use that stale state before initialization resets it, potentially leading to remote code execution.

      Weakness CWE-416 — Use after free
